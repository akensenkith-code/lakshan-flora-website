# Lakshm Flora Website

Lakshm Flora is a responsive flower shop website developed as part of my HND Software Engineering studies.

## Project Description

This project was created to provide a simple and attractive online presence for a flower business. The website includes information about the company, flower products, services, contact details, and other relevant content.

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Responsive Web Design

## Features

* Responsive website layout
* Navigation menu
* Flower product sections
* Image gallery
* Contact section
* Interactive JavaScript features
* Mobile-friendly design

## Purpose

This project helped me develop practical skills in front-end web development, responsive design, JavaScript, file organization, and website development.
